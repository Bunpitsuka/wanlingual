# 開発ルール（夜間の自動作業も含めて必ず守る）

社長の指示書（非公開）の要点。自動作業はこのファイルと `docs/plan.md` を読んでから始める。

## プロジェクト
犬の鳴き声 → 6つの気持ち（警戒・威嚇・要求・遊ぼう・さみしい・うれしい）に推測 → 飼い主が正解を教えると「うちの子専用」に育つ PWA。
将来は首輪型デバイスの仮予約 → クラファン。**本物の翻訳ではなく「吠え方の特徴からの推測」であることを常に UI に明示**。

## フェーズ
1. スマホで動く単体アプリ（完了、公開中: https://bunpitsuka.github.io/wanlingual/ ）
2. 判定精度の改善: YAMNet（TensorFlow.js、CDN 固定版）で犬以外の音を除外、MFCC 等の特徴量追加、公開データ（CC 系ライセンスのみ）、匿名化特徴量の収集バックエンド（Cloudflare Workers + D1 か Supabase 無料枠、**同意チェックボックス必須**）。完了条件: 本物の犬 20件で的中率を `docs/accuracy.md` に記録。
3. 仮予約・クラファン事前登録ページ（成犬以上で解放、**お金は取らない**、フォームは D1/Supabase に保存、社長が CSV で取り出せる）。
4. 保留（社長の指示があるまで着手しない）: Android ネイティブ版、ESP32 首輪。

## 技術方針
- 素の HTML/CSS/JS、ビルド不要。依存最小、ライブラリは CDN から固定バージョン。
- デザイントークンは `app/css/app.css` のまま（LCD 風の緑、DotGothic16 / Zen Kaku Gothic New、ライト／ダーク）。
- 文言は日本語。
- **音声データは端末から出さない**。送るのは特徴量と正解ラベルだけ。
- テスト: `npm run test:unit`、`npm run test:e2e`。壊れたままにしない。
- `app/` を変えたら `app/sw.js` の VERSION を上げる。

## 自動でやってよいこと
コミット、main への push（Pages へ自動デプロイ）、公開データセットの調査（ライセンス確認必須）、精度計測と `docs/accuracy.md` 更新、`docs/daily/YYYY-MM-DD.md` の日報。

## 必ず止まって社長に聞くこと（日報の「社長に聞きたいこと」に書いて、やらない）
- お金が動くこと全部: 決済導入、有料サービス契約、広告出稿。
- 外部アカウントの新規作成、規約同意、OAuth 連携。
- note・Threads・X など社長名義・会社名義での公開投稿（投稿文の下書きは可）。
- ユーザーの個人情報（メール等）を保存する仕組みの初回稼働。
- 製品名・価格・クラファン文面の確定。
- 会社の屋号（改名検討中）: UI にも公開リポジトリにも出さない。
- 社長の本名・勤務先・住所・家族のこと: どこにも書かない。

## 日報の形式（`docs/daily/YYYY-MM-DD.md`）
```
# YYYY-MM-DD
## やったこと
## 数字（的中率・デプロイURL・テスト結果）
## 失敗・詰まったこと
## 明日やること
## 社長に聞きたいこと（あれば）
## AI費用（概算）
```
