## 設計のポイント

- 音声は端末から出さない。保存するのは特徴量7つ（n, dur, gap, f0, cent, gapCv, durCv）と正解ラベル、判定、時刻だけ。
- 判定 = ルール（Pongrácz 2005 を単純化）と、飼い主が教えたサンプルの kNN（k=5、距離重み）を、サンプル数 n に応じて n/(n+8) でブレンド。試作と同じ。
- iPhone はバックグラウンド録音ができないので、画面が隠れたら監視を止めて通知する。Wake Lock で監視中は画面を消さない。
- 「本物の翻訳ではなく推測」を判定欄・注意書きの2か所に常時表示。
- 屋号は UI に出していない。

## plan #14 の設計メモ（2026-11-05。YAMNet を本体 mic.js の前段に入れる）

計測（`docs/accuracy.md` 2026-11-03〜05）から決めたこと。実装はこのメモどおりに小さく進める。

1. **渡す単位と範囲**: mic.js が確定した「吠えの塊」そのもの（約 1 秒）ではなく、リングバッファ（過去 6 秒）から**前を足して最低 MIN_SEC 秒の実音**を渡す。未来の音は待たない（判定の遅れを増やさない）。**MIN_SEC = 2**（2026-11-05 の計測: 2 秒で犬 94%・犬以外 0%、3 秒は犬以外を 1 塊拾う。`docs/accuracy.md`）。`Listener` に `contextSec` を足し、`onCluster(x, sr, { wide })` の第 3 引数で文脈つき波形を渡す。特徴量（気持ちの判定）は従来どおり塊そのもの `x` から取る。
2. **しきい値**: 犬らしさ（犬系 7 クラスの最大値）**0.3**。犬系の合計 dogSum は使わない。
3. **3 つの状態**: (a) **未準備／オフ／オフライン** → 従来どおり音量だけで動く（いまと同じ）。(b) **犬（0.3 以上）** → 従来どおり判定して履歴に残す。(c) **犬以外っぽい（0.3 未満）** → **捨てない**。判定はするが薄く表示し（「犬の声ではないかも」の注記）、育成ログには自動では残さない。飼い主が正解をタップしたら、その時点で「犬」と確定して通常どおり保存する（くんくん・息が落ちても「さみしい」を教えられる）。履歴の件数・吠え回数の表示は (b) だけを数える。
4. **読み込み**: tfjs 4.22.0（jsdelivr 固定版）とモデル（TF Hub v1、約 15MB）は**監視を開始してから裏で**読む（`<script>` を動的に足す。初回のみ、2 回目はブラウザキャッシュ）。読めるまで・失敗したら (a)。service worker の事前キャッシュには入れない（本体のオフライン起動を重くしない）。
5. **既定はオフ**: `app/js/dogcheck.js`（仮）として入れ、設定（localStorage `wl.dogcheck`）で明示的に「オン」にしたときだけ読む。E2E は既定オフのまま通す（ネットに出ない）。スマホの処理時間（塊 1 つ CPU 0.3〜0.5 秒＝Actions のランナー。実機は未計測）と電池への影響を実機で見てから既定オンを検討する。
6. **順番**: ①`Listener.contextSec` と第 3 引数（単体テスト）**＝完了 2026-11-05** → ②`dogcheck.js` の読み込み・判定（実験室 `app/lab/yamnet.js` の純粋関数をそのまま import）**＝完了 2026-11-06** → ③状態 (c) の表示と「教えたら保存」**＝完了 2026-11-07** → ④設定トグル**＝完了 2026-11-08**。1 晩 1 つずつ。
7. **② で分かったこと（③・④ で反映する）**: (i) 推論は 2 秒の音に約 0.9 秒（Actions のランナー）かかるので、**判定は待たせずに先に出し、犬らしさは後から届く**。③ の「薄く表示」は後から薄くする形になる（先に通常表示 → 0.3 未満と分かったら薄くして注記）。(ii) いまの `sw.js` は外部オリジンの GET を全部「ネットワーク優先＋キャッシュに保存」するので、オンにすると tfjs とモデル（約 15MB）も Service Worker のキャッシュに入り、VERSION を上げるたびに消える。既定オンにする前に、jsdelivr / tfhub / kaggle は SW のキャッシュに入れない（ブラウザの HTTP キャッシュに任せる）ように直す。**→ 2026-11-07 に対応済み**（`sw.js` wl-v9: 外部オリジンでキャッシュするのは fonts.googleapis.com / fonts.gstatic.com だけ。それ以外は respondWith しない）。(iii) tfjs の `<script>` に SRI（integrity）を付ける（npm の tarball からハッシュを出し、Actions で実際に読めることを確かめてから）。**→ 2026-11-08 に対応済み**（`TFJS_SRI`。E2E の偽 tf は、同じページの `lab/yamnet.js` の `TFJS_SRI` も偽のハッシュに差し替えて通す。Service Worker が効いている E2E では差し替えられないので「偽 tf は SRI で拒まれて failed になる」ことを確かめる形にした）。(iv) 録音ファイル読み込みにはまだ犬の声チェックを掛けていない（マイク監視だけ）。

8. **③ で決めたこと（2026-11-07）**: (i) 状態 (c) は「まだ答えを待っている判定」にだけ掛ける。犬らしさが届く前に飼い主が教えた・「わからない」を押した場合は何もしない（数字を添えるだけ）。(ii) 育成ログへの保存はもともと「飼い主が教えたときだけ」なので、(c) で追加で止めるものは無い。変えたのは表示（薄くする・注記）と「吠え ◯回」の数え方だけ。(iii) 前の推論がまだ終わっていない・推論に失敗した塊は状態 (a) 扱い（従来どおり数える）。(iv) 録音ファイル読み込みにはまだ掛けていない（7-iv のまま）。
