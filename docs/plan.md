## 設計のポイント

- 音声は端末から出さない。保存するのは特徴量7つ（n, dur, gap, f0, cent, gapCv, durCv）と正解ラベル、判定、時刻だけ。
- 判定 = ルール（Pongrácz 2005 を単純化）と、飼い主が教えたサンプルの kNN（k=5、距離重み）を、サンプル数 n に応じて n/(n+8) でブレンド。試作と同じ。
- iPhone はバックグラウンド録音ができないので、画面が隠れたら監視を止めて通知する。Wake Lock で監視中は画面を消さない。
- 「本物の翻訳ではなく推測」を判定欄・注意書きの2か所に常時表示。
- 屋号は UI に出していない。
