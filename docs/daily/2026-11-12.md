## 失敗・詰まったこと
- **deploy-pages が落ちた**: `deploy-pages` の単体テストは `npm ci` 無しで走る（`.github/workflows/pages.yml`。`node --test` だけなので依存を入れていない）。新しい `tools/og-image.mjs` が先頭で `import { chromium } from 'playwright'` していたため、それを読む単体テスト `og-image.test.mjs` が Actions では `Cannot find package 'playwright'` で落ちた（手元は E2E 用に入っているので通っていた）。**直し**: playwright は画像を撮る `main()` の中で `await import('playwright')` する形にして、`buildHtml` を読むだけなら要らないようにした。手元で `node_modules/playwright` を一時的に外して単体テスト 52/52 が通ることを確認。教訓: deploy-pages の単体テストは依存ゼロで走る前提なので、`tools/` や `tests/unit/` から import するものは Node 標準と `app/` だけにする。
- この作業環境では今夜も `npx playwright install chromium` は使わず、`PLAYWRIGHT_CHROMIUM_EXECUTABLE` で手元の Chromium を指して E2E と OGP 生成を回した（GitHub Actions 側は従来どおり）。
- Google Fonts にはこの環境から届かない（CONNECT 403）。OGP 生成は npm の `@fontsource` パッケージ（同じ字体の配布版）をローカルに入れて同じ見た目にした。`package.json` には入れていないので、社長の PC や Actions で `npm run og` するときは、フォントが無ければ Google Fonts から読む（ネット有りなら同じ絵になる）。
